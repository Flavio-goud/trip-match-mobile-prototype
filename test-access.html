Tester Trip Match sur web et Android

Cette page centralise les accès de test. Tu peux ouvrir la version web depuis un PC ou un mobile, et la version Android via Google Play en test fermé.

Version web

C’est la version la plus simple pour tester immédiatement depuis un navigateur sur PC ou téléphone.

Ouvrir la version web Ouvrir le prototype web
  1. Scanne le QR code avec ton téléphone
  2. Ou ouvre directement native-web-build
  3. Teste l’app dans le navigateur

Version Android (Google Play)

Cette version passe par le test Play Store. Il faut être connecté avec une adresse invitée dans la liste des testeurs.

Participer au test Android
  1. Scanne le QR code avec le téléphone Android
  2. Connecte-toi avec un Gmail testeur autorisé
  3. Accepte la participation au test
  4. Installe l’application depuis Google Play
Important : la fiche publique Google Play store/apps/details peut rester indisponible tant que l’app est en test fermé. Le bon lien pour Android est le lien de participation au test ci-dessus.
