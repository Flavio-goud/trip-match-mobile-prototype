Version Android (Google Play)

Sur Android, il faut faire le parcours dans cet ordre avec un Gmail invité comme testeur.

1. Rejoindre le test fermé 2. Ouvrir la fiche Play Store après adhésion
  1. Scanne le QR code ou clique sur Rejoindre le test fermé
  2. Connecte-toi avec une adresse testeur autorisée
  3. Accepte la participation au test
  4. Ensuite utilise le bouton Ouvrir la fiche Play Store après adhésion
  5. Installe l’application
Si l’installation Android échoue encore : cela vient presque toujours du compte Google utilisé sur le téléphone. Il doit être le même que l’adresse invitée dans la liste des testeurs, puis il faut d’abord rejoindre le test via le lien apps/testing avant d’essayer la fiche Play Store.
